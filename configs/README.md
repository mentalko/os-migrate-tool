# configs/ — пользовательская конфигурация os-migrate-tool

Правь только здесь. `src/` — код, его трогать не нужно.
Парсер — `src/conf.py` (мини-YAML на stdlib; для mapping.toml — stdlib tomllib,
python ≥ 3.11). Комментарии: целые строки + инлайн ` #` (в значениях `#` не использовать).

## inventory.yaml — инвентарь путей
Полный перечень того, что **можно** паковать: группы `group_<имя>`, внутри секции
(`home`/`config`/`sessions` у агентов, `dirs`+`files` у dotfiles, `paths` у остальных),
секция `desc:` — описания пунктов для чеклиста. Несуществующие пути автоматически
пропускаются. Добавил путь — добавь описание в `desc:`.

## selection.yaml — галочки по умолчанию
Дерево повторяет чеклист: `group_<имя>.on` — группа, вложенные `путь: true/false` —
точечно. Не упомянутые подпункты наследуют группу. ON-подпункт едет даже внутри
выключенной группы. Ручные галочки в чеклисте pack.sh перекрывают всё.

## exclude_dirs.yaml — что не пакуем
`tar:` — шаблоны `--exclude-from`, применяются ко всем сегментам. Без хвостового
`/` (tar матчит имя каталога без слэша). `appimages.skip_zero_size: true` — битые/
пустые AppImage не переносятся (условие, не по имени).

## mapping.toml — пакеты Ubuntu → установка на CachyOS
`[packages.<имя>]`: `status` = native (репозитории) / aur (yay) / manual / skip;
`cachyos` — команда установки (выполняется unpack'ом только для native/aur);
`url` — страница скачивания для manual. Нет записи → пакет не ставится, попадает
в missing-mapping.txt. `[appimages."<файл>"]` → `url` — ссылка на скачивание.
unpack в конце печатает названия и ссылки (flatpak → flathub, manual, appimages) —
сам он ниоткуда не качает и не устанавливает.
